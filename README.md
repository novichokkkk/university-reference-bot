# university-reference-bot

Учебный проект по дисциплине «Конструирование программного обеспечения».

## Стек

- Java 21
- Spring Boot
- Maven
- PostgreSQL
- JUnit

## Запуск

Убедись, что PostgreSQL запущен и база `university_reference_bot` создана, затем выполни:

```bash
mvn spring-boot:run
```

Проверка доступна по адресу: http://127.0.0.1:8080/reference.html.
При запуске Flyway сам применяет миграции базы, включая контакты факультетов.

## Telegram

Напиши боту `/start`. Появятся кнопки «Расписание», «Факультеты», «Профиль»,
«Темы», «Помощь» и «Админка».

- В «Профиле» нажми «Изменить группу» и отправь её название одним сообщением.
  Группа сохраняется для твоего Telegram ID в PostgreSQL. Например, `ПИбд-42`.
- В «Расписании» выбери день кнопкой. Бот возьмёт группу из профиля.
- В «Факультетах» выбери подразделение. Бот покажет телефон, почту и источник
  с сайта УлГТУ. Доступны десять факультетов.
- В «Темах» есть поступление, общежитие и стипендия. Также можно писать
  вопросы обычным текстом.
- Команды `/group ГРУППА`, `/schedule 1`, `/contacts НАЗВАНИЕ` продолжают работать.

Составленное для учебного проекта расписание есть только для группы `ПИбд-42`.
Контакты факультетов взяты с официальных страниц УлГТУ.

## Админка

Админка работает в браузере на компьютере, где запущено приложение:
http://127.0.0.1:8080/reference.html. Она позволяет просматривать, добавлять,
изменять и удалять основные ответы базы знаний. Профиль и группу каждый
пользователь меняет сам в Telegram; админка для этого не нужна.

Для включения админки задай переменную окружения `ADMIN_KEY` в конфигурации
запуска IntelliJ IDEA или терминала. Не сохраняй ключ в Git и не отправляй его
боту. Если `ADMIN_KEY` не задан, административный API выключен.

Тесты используют встроенную H2-базу:

```bash
mvn test
```
